# AP FlashPass - 応用情報技術者 午前一問一答フラッシュ学習ツール

応用情報技術者試験（AP）の午前問題で頻出する「重要用語・英字略語・定義」を、**完全広告ゼロ・1問1秒のテンポ**で脳に叩き込むための特化型フラッシュカード＆クイズWebツールです。
デザインシステム標準（トークン管理・控えめで端正なミニマルUI・WCAG AA準拠）に基づいて設計されています。

---

## 🌟 主な特徴

1. **ミニマルで洗練されたUI（デザインシステム準拠）**
   - 不要なネオン発光や装飾を削ぎ落とし、集中を妨げないクリーンで目に優しいモノトーン基調の端正なUI。
2. **完全広告なし・爆速レスポンス**
   - 既存アプリのような全画面広告や煩わしい通信待ちが一切ありません。
3. **PC特化の爆速キーボード操作（Anki風）**
   - `Space` でめくり、`1`（要復習）/ `2`（覚えた）で秒速仕分け。
4. **スマホ完全対応（レスポンシブ & タッチ最適化）**
   - 通学・通勤電車内でも片手タップでサクサク回せます。
5. **午前試験の「決定打キーワード」を完全網羅**
   - 単なる用語解説ではなく、「午前試験でこのキーワードが出たらこれを選ぶ」という得点直結のポイントを全問に記載。
6. **双方向出題（リバーシブル）対応**
   - 「説明文 ➜ 用語を当てる（午後試験の記述対策にも直結！）」
   - 「用語 ➜ 定義を思い出す」
7. **4択スピードクイズモード**
   - 同じ分野の単語からダミー選択肢を自動生成。連続正解（ストリーク）カウント付きで腕試しができます。
8. **進捗保存 & 弱点集中フィルター**
   - ブラウザの LocalStorage に自動保存。「要復習（苦手）のみ」「未着手のみ」「ブックマークのみ」を絞り込んで徹底反復可能。

## 🚀 起動方法

### 方法1: ダブルクリックで即起動（最も簡単・サーバー不要）
フォルダ内の **`index.html`** をダブルクリックして、普段お使いのブラウザ（Google Chrome, Edge, Safari など）で開くだけですぐに使用できます。

### 方法2: ローカルHTTPサーバーで起動
ターミナルまたはPowerShellで以下を実行し、ブラウザで `http://localhost:8000` を開きます。
```bash
python -m http.server 8000
```

## ⌨️ キーボード操作一覧（PC利用時）

| キー | 動作 |
| :--- | :--- |
| **`Space`** / **`Enter`** | カードを裏返す（めくる） |
| **`1`** | **要復習（苦手）** として記録し、次のカードへ |
| **`2`** | **覚えた（習得）** として記録し、次のカードへ |
| **`←`** / **`P`** | 前のカードに戻る |
| **`→`** / **`N`** | 次のカードへ進む |
| **`3`** / **`B`** | ブックマーク（⭐）のON/OFF |
| **`R`** | 出題方向の反転（説明 ➜ 用語 / 用語 ➜ 説明） |
| **`S`** | シャッフル出題のON/OFF |
| **`1`〜`4`** | 4択クイズモードで選択肢を選ぶ |

## 📱 スマホで使う方法（GitHub Pagesで自分専用アプリ化）

通勤・通学中にスマホで使いたい場合、GitHubのリポジトリにプッシュして **GitHub Pages** を有効化するのが最もおすすめです。

1. 本フォルダを GitHub のリポジトリに push します。
2. GitHubリポジトリの **Settings ➜ Pages** を開きます。
3. Branch を `main`、Folder を `/ (root)` に設定して **Save** をクリックします。
4. 数分で `https://<ユーザー名>.github.io/<リポジトリ名>/` という自分専用のURLが発行されます。
5. スマホのブラウザ（SafariやChrome）で開き、**「ホーム画面に追加」** すると、ネイティブアプリのように全画面・広告ゼロで利用できます。
